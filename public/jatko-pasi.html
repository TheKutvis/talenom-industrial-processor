Jatko-PASI

Industrial Data Merger - Combining tire POIS and POLO PASI files with precision

🔧 How Jatko-PASI Works

  • Reads data from files containing "44841_tire" and "_POIS" in the name
  • Extracts numbers that appear after ";;;" in those files
  • Finds files containing "44841TPM" and "_POLO_PASI" in the name
  • Merges the data by matching IDs and appending tire numbers to PASI rows
  • Creates an updated output file with the merged data for download
